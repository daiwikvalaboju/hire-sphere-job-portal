# Hire Sphere - Job Portal

## 📌 Description

Hire Sphere is a web-based job portal application developed using Java. It connects job seekers and recruiters on a single platform, allowing users to search and apply for jobs while enabling employers to post and manage job listings efficiently.

---

## 🚀 Features

* User Registration & Login
* Job Search and Filtering
* Apply for Jobs
* Resume Upload
* Recruiter Dashboard
* Notifications System

---

## 🛠 Tech Stack

* **Backend:** Java (Spring Boot)
* **Frontend:** HTML, CSS, JavaScript
* **Database:** MySQL

---

## 📂 Project Structure

* `backend/` → Java backend (Spring Boot)
* `frontend/` → UI files
* `uploads/` → (ignored in Git)

---

## ▶️ How to Run

### Backend

1. Open backend folder
2. Run the application using:

```
mvn spring-boot:run
```

### Frontend

1. Open `index.html` in browser
   OR
2. Use live server
